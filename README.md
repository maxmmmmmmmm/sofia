# Sofia Filatova — сайт

Статический сайт фотографа. Собирается генератором на Python 3 (только стандартная
библиотека, без Node и без сборщиков).

## Пересобрать

```
python3 src/build.py
```

Генератор перезаписывает `*.html` в корне и папку `tilda/`. Править нужно исходники,
а не готовые страницы:

| файл | что в нём |
|---|---|
| `src/content.py` | весь текст, на русском и английском |
| `src/photos.py` | список фотографий и их пропорции |
| `src/build.py` | разметка блоков |
| `assets/css/style.css` | стили |
| `assets/js/main.js` | поведение |

## Посмотреть локально

```
python3 -m http.server 4321
```

и открыть `http://localhost:4321`. Телефонную ширину проще смотреть прямо с
телефона: тот же адрес, но вместо `localhost` — адрес компьютера в сети, его
печатает пусковой файл. Папка `варианты/` — листы сравнения раскладок, по
которым выбирался дизайн; в репозиторий она не попадает.

## Перенос на Tilda

Папка `tilda/` — блоки для вставки в T123, по одному файлу на блок.
Порядок и назначение описаны в `tilda/README-TILDA.md`.
